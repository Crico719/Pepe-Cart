# 🏎️ Super Kart Racing

Un juego de carreras estilo **Mario Kart** desarrollado con HTML5 Canvas y JavaScript vanilla. Sin dependencias, funciona directamente en el navegador.

## 🎮 Características

- **4 karts** compitiendo (1 jugador + 3 oponentes con IA)
- **Física de kart**: aceleración, frenos, marcha atrás y derrape (drift) con mini-turbo
- **Pista de circuito** con césped que reduce la velocidad al salirte
- **Sistema de ítems** estilo Mario Kart:
  - 🍄 **Hongo** — turbo de velocidad
  - 🍌 **Plátano** — déjalo atrás para hacer resbalar a tus rivales
  - 🐢 **Caparazón verde** — dispáralo hacia adelante, rebota y hace tambalear
- **3 vueltas** a la pista con detección de checkpoints
- **Posiciones en tiempo real**, velocímetro y contador de vueltas
- **Minimapa** con la posición de todos los karts
- **Pantalla de resultados** con tiempos y clasificación final

## 🕹️ Controles

| Tecla | Acción |
|-------|--------|
| `↑` / `W` | Acelerar |
| `↓` / `S` | Frenar / Marcha atrás |
| `← →` / `A D` | Girar |
| `Shift` | Derrape (drift) — suelta después de un momento para obtener mini-turbo |
| `Espacio` | Usar ítem |
| `R` | Reiniciar carrera |

## 🚀 Cómo jugar

1. Descarga o clona este repositorio
2. Abre `index.html` en cualquier navegador moderno
3. ¡Pulsa "¡EMPEZAR CARRERA!" y a correr!

No requiere servidor ni instalación de dependencias.

## 🛠️ Tecnología

- HTML5 Canvas 2D
- JavaScript (ES6+) — sin librerías externas
- CSS para la interfaz (HUD y pantallas)
